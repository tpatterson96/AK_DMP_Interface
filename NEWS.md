# Data_Management_Plan_App 0.2.1

Browser application that assists FWS staff to create a Data Management Plan that 
- meets FWS policy
- generates file to draft mdEditor metadata files for the project and products via jupyter notebook python script
- creates an internal preservation repository for the project--pending
- includes the 2026 records schedule update--pending
- creates a csv file that feeds into the National DMP SharePoint list via jupyter notebook python script

-  Please email tamatha_patterson@fws.gov and calyen_cummings@fws.gov with suggestions for added features
